## 3. دليل الخطوط والطباعة المستخدمة في المنظومة (Typography)

تستخدم المنظومة حزمة خطوط عربية حديثة وأيقونات متجهة عالية الدقة لضمان سرعة التحميل وجمالية العرض:

1. **خط المراعي (`Almarai`):**
   - **الاستخدام:** الخط الأساسي لواجهة تسجيل الدخول المتطورة، الحقول، الأزرار، والبطاقات العامة.
   - **الملف المصدري:** `assets/fonts/Almarai.woff2` مع ملف التنسيق `assets/fonts/Almarai.css`.
   - **الأوزان المضمنة:** Normal (300)، Semi-Bold (600)، Bold (700).
   - **نطاق المحارف:** يدعم اللغة العربية الكاملة وعلامات التشكيل اللاتينية والأرقام القياسية (`U+0600-06FF`).

2. **خط تجوال (`Tajawal`):**
   - **الاستخدام:** مستخدم في كروت الأسعار والباقات والأزرار التفاعلية في صفحة `prices.html`.
   - **الخاصية:** خط هندسي عصري مقروء بوضوح على شاشات الهواتف المحمولة الصغيرة.

3. **خط كايرو (`Cairo`):**
   - **الاستخدام:** مستخدم في عنوان وقسم اختيار السرعة الحديث (Speed Selector) في `login.html`.
   - **النمط:** `font-family: 'Cairo', sans-serif` مع ظل نصي `text-shadow: 0 0 12px rgba(255,255,255,0.4)`.

4. **خط نوتو كوفي العربي (`Noto Kufi Arabic`):**
   - **الاستخدام:** مستخدم في صفحة متابعة الاستهلاك ولوحة الحالة `status.html`.
   - **الخاصية:** يعطي طابعاً رسمياً وواضحاً للأرقام والعدادات والوحدات.

5. **خط درويد كوفي العربي (`Droid Arabic Kufi`):**
   - **الاستخدام:** خط متاح في مجلد `fonts/` بصيغ `DroidKufi-Regular` و `DroidKufi-Bold` (.eot, .ttf, .woff, .woff2).

6. **مكتبات الأيقونات المتجهة (Icon Fonts):**
   - **Fontello Icons:** معرّف في `assets/css/fontello.css` ويوفر أيقونات:
     - `icon-signal`: إشارة الشبكة والبث.
     - `icon-login`: تسجيل الدخول والخروج.
     - `icon-dollar`: باقات الأسعار والعملات.
     - `icon-whatsapp`: الواتساب والدعم الفني.
     - `icon-phone`: الاتصال الصوتي وخدمة العملاء.
     - `icon-location`: الموقع ونقاط البيع المعتمدة.
     - `icon-error`: تنبيهات الأخطاء.
     - `icon-user`: حساب المشترك.
   - **FontAwesome:** معرّف في `assets/css/font-awesome.css` و `assets/fonts/fontawesome-webfont.ttf`.

## 4. لوحة الألوان والتدرجات والظلال والتأثيرات البصرية (Design Tokens)

### أ. لوحة ألوان الخلفيات (Backgrounds):
- **خلفية صفحة الدخول المتطورة (`login.html`):**
  - تدرج شعاعي ياقوتي فاخر: `radial-gradient(circle at 50% 20%, #4a0018 0%, #2b000e 50%, #150007 100%)`
  - اللون الأساسي المحيط: `#2b000e` و `#1a0108`
- **خلفية صفحة الأسعار (`prices.html`):** كحلي ليلي داكن `#1c1c2e`.
- **خلفية صفحة الاستهلاك (`status.html`):** تدرج شعاعي بترولي `radial-gradient(#0A7294, #032936)`.
- **خلفية الوضع الليلي (Dark Mode):** رمادي ليلي عميق `#202124` مع نص `rgba(255,255,255,0.7)`.

### ب. ألوان الحاويات والبطاقات المتطورة (Glassmorphic Containers):
- **بطاقة تسجيل الدخول الزجاجية الفاخرة (`.glass-card` / `--bg-card`):** خلفية زجاجية ياقوتية داكنة `rgba(55, 4, 18, 0.82)` مع حد ذهبي شامبانيا `rgba(229, 192, 123, 0.22)` وضبابية زجاجية `backdrop-filter: blur(14px)`.
- **شريط الملاحة السفلي العائم (`.top-navbar`):** خلفية زجاجية `rgba(36, 3, 11, 0.78)` بضبابية `blur(20px)` مع حد ذهبي شامبانيا `rgba(245, 215, 127, 0.28)` وزوايا دائرية `24px` وأيقونات تفاعلية بنمط عصري.
- **شريط حالة السيرفر (`.server-status-bar`):** خلفية `rgba(75, 8, 26, 0.9)` مع نقطة اتصال حية نابضة (`.live-dot`) بلون أخضر مضيء `#00e676`.
- **بطاقات الأسعار (`.card`):** خلفية `#2a2a3d`، حواف `border-radius: 15px / 20px`، تأثير رفع عند التحويم `transform: translateY(-6px)` وظلال `box-shadow: 0 8px 20px rgba(0,0,0,0.25)`.
- **صندوق الاستهلاك في `status.html` (`.box`):** خلفية بيضاء `#ffffff`، حافة سفلية عريضة `border-bottom: 4px solid #0085DE`، وظلال مجسمة `box-shadow: 0px 0px 15px 0px rgba(0,0,0,0.75)`.

### ج. ألوان بطاقات عدادات الاستهلاك في صفحة الحالة:
- **الوقت المستخدم (`.card`):** أزرق غامق `#006AC7`
- **الوقت المتبقي (`.remain`):** برتقالي ناري `#C75000`
- **الرصيد المتبقي الكلي (`.final`):** وردي ماجينتا غامق `#A60088`
- **اسم المستخدم (`.username`):** أحمر قرمزي `#C70000`

### د. ألوان وتدرجات النصوص والشعارات:
- **توهج الشعار الذهبي والألوان الياقوتية:**
  - الذهب الشامبانيا: `#F5D77F`
  - التوهج الذهبي: `rgba(229, 192, 123, 0.45)`
  - إطار الذهب الملكي: `#d4af37`
  - أيقونة الواي فاي المتتالية المتحركة: موجات متتابعة تنبض باللون الذهبي الشامبانيا `#FFF0B3` مع وميض `drop-shadow(0 0 8px #F5D77F)`.
- **عنوان اسم الشبكة المتحرك (`.animated-title`):**
  - تدرج لوني رباعي: `linear-gradient(270deg, #8e2de2, #ff6ec4, #ff9a8b, #f6416c)`
  - قص الخلفية على الحروف مع توهج نصي لطيف.

### هـ. ألوان الأزرار التفاعلية (Buttons):
- **زر تسجيل الدخول الأساسي الفاخر:** أحمر ياقوتي متدرج مع وميض وتوهج ذهبي وتأثير نبض عند الضغط.
- **زر تسجيل الخروج في صفحة الاستهلاك:** أخضر زمردي `#15B300` ويتحول عند التحويم إلى `#108C00`.
- **أزرار التنقل والرجوع:** أزرق سماوي `#00AAE3` و `#1a73e8` و `#2980B9`.

### و. ألوان الأيقونات العائمة والملاحة السريعة:**

## 5. الشريط الإخباري التفاعلي (News Ticker / Marquee) بالتفصيل الحرفي

تم تصميم الشريط الإخباري ليكون عنصراً إرشادياً وترويجياً جذاباً للمشتركين:

### أ. خصائص التصميم والـ CSS للشريط:
```css
.marque {
  background-color: #2E003E;                  /* بنفسجي ملكي غامق وفاخر */
  color: #FF9A8B;                             /* نص وردي مشرق دافئ ومريح للعين */
  font-size: 17px;                            /* حجم خط مثالي ومقروء بوضوح */
  padding: 10px;                              /* تباعد داخلي مريح */
  border-radius: 10px;                        /* زوايا دائرية ناعمة */
  box-shadow: 0 0 12px rgba(255, 154, 139, 0.4); /* توهج وإضاءة وردية خافتة */
  font-weight: bold;                          /* خط عريض */
}
```

### ب. السلوك التفاعلي للوسم:
- **اتجاه الحركة:** يتحرك نحو اليمين بانسيابية (`direction="right"`).
- **السرعة:** سرعة قراءة مريحة معتدلة (`scrollamount="4"`).
- **التوقف عند القراءة:** يتوقف فوراً عند وضع مؤشر الفأرة أو لمس الشاشة (`onMouseOver="this.stop();"`)، ويستأنف الحركة تلقائياً عند الإبعاد (`onMouseOut="this.start();"`).

### ج. النص الإخباري الكامل والعبارات المضمنة:

## 6. حاويات التصميم والواجهات والعناصر التفاعلية (UI Containers & Components)

### 1. بطاقة الدخول الزجاجية الياقوتية الفاخرة (Luxury Ruby Glass Card):
- **النمط الجمالي:** تصميم زجاجي معتم فاخر بنمط Glassmorphism.
- **الخلفية:** `rgba(55, 4, 18, 0.82)` مع ضبابية زجاجية فائقة `backdrop-filter: blur(14px)`.
- **الإطار والحدود:** حد ناعم بذهب الشامبانيا `1px solid rgba(229, 192, 123, 0.22)` وزوايا دائرية مقوسة بانسيابية.
- **الظلال والتوهج:** `box-shadow: 0 15px 35px rgba(0, 0, 0, 0.6), 0 0 20px rgba(229, 192, 123, 0.15)`.

### 2. شريط التنقل السفلي العائم (Floating Bottom Navigation Bar):
- **الموقع:** عائم ومثبت في أسفل الشاشة بمركزية تامة (`position: fixed; bottom: 14px; left: 50%`).
- **التصميم:** كبسولة زجاجية ياقوتية فاخرة `rgba(36, 3, 11, 0.78)` مع إطار ذهبي وضبابية `blur(20px)` وزوايا دائرية `24px`.
- **العناصر التفاعلية:** أيقونات الملاحة السريعة (دخول، باقات الأسعار، اتصل بنا، مراكز البيع، تجديد) مع تمييز التبويب النشط بتدرج ذهبي لامع.

### 3. شريط حالة السيرفر والاتصال الحي (Server Status Bar):
- **المظهر:** كبسولة علوية `rgba(75, 8, 26, 0.9)` محاطة بحد ياقوتي مضيء `border: 1px solid rgba(255, 75, 110, 0.35)`.
- **المؤشر النبضي (`.live-dot`):** نقطة خضراء متوهجة `#00e676` تنبض بشكل مستمر (`animation: pulseDot 1.8s infinite`) للدلالة على استقرار اتصال شبكة المايكروتك.

### 4. شعار البث اللاسلكي المتتالي المتحرك (Cascading Animated Wi-Fi Waves):
- **التصميم:** صندوق أيقونة عائم بتدرج ياقوتي وذهبي `linear-gradient(135deg, rgba(245, 215, 127, 0.25), rgba(196, 30, 58, 0.4), rgba(85, 5, 25, 0.8))`.
- **الحركة التفاعلية:** موجات بث SVG متتابعة (نقطة، قوس 1، قوس 2، قوس 3) تنبض بتوهج ذهبي شامبانيا متتابع يعكس قوة الإشارة.

### 5. حاوية قسم اختيار السرعة الحديثة (Speed Selector Glassmorphism Container):
- **النمط الجمالي:** تصميم زجاجي نصف شفاف متطور (Glassmorphism).
- **الخلفية:** `linear-gradient(135deg, rgba(75,0,130,0.6), rgba(186,85,211,0.6))`
- **الضبابية الزجاجية:** `backdrop-filter: blur(10px)`
- **الإطار:** حد زجاجي أبيض ناعم `border: 1px solid rgba(255, 255, 255, 0.25)`
- **الحواف والظلال:** `border-radius: 18px` مع ظل نيون `box-shadow: 0 6px 25px rgba(155, 89, 182, 0.4)`.
- **القائمة المنسدلة (`<select name="domain">`):**
  - خلفية ناعمة بتدرج لافندر: `linear-gradient(90deg, #ede7f6, #f3e5f5)`.
  - حواف دائرية `12px` مع ظل داخلي ثلاثي الأبعاد `box-shadow: inset 0 0 8px rgba(0,0,0,0.1)`.
  - الخيارات: "سرعة ضعيفة" (`512K/512K`) و "سرعة قوية" (`100M/100M` - محددة افتراضياً).

### 6. ساعة النظام والتاريخ العربي الحي (`#clock`):
- **التصميم:** صندوق زجاجي مقوس `border-radius: 10px / 20px` بخلفية نصف شفافة `rgba(255, 255, 255, 0.05)`.
- **الدالة البرمجية (`refrClock()`):** تحسب الوقت بدقة 1 ثانية، وتعرض:
  - اسم اليوم باللغة العربية (الأحد، الإثنين، الثلاثاء، الأربعاء، الخميس، الجمعة، السبت).
  - رقم اليوم والشهر باللغة العربية مع السنة الحالية.
  - الساعة والدقيقة والثانية بصيغة 12 ساعة متبوعة بـ (صباحاً / مساءً).

### 7. مفتاح حفظ الكود (Remember Me Toggle):
- **المظهر:** مفتاح تبديل انسيابي من فئة `ios-toggle` مع نصين تفاعليين: `"تذكرني"` (في حالة التفعيل) و `"لا تتذكرني"` (في حالة الإلغاء).

### 8. حقل إدخال كرت الدخول (Username Input):
- **التنسيق:** حقل مركزي بحواف دائرية `8px`، تباعد داخلي مريح `12px`، حجم خط `16px`، مع عبارة إرشادية `"أدخل الكود هنا"`.

### 9. النوافذ المنبثقة التفاعلية (Pop-up Modals & Overlays):
- **نافذة اتصل بنا (`alert-phone`):**
  - عنوان نيون فيروزي: `#00ffcc` مع أيقونة الهاتف.
  - خط فاصل بتدرج ليزري: `linear-gradient(to right, #00f0ff, #a100ff)`.
  - بطاقة الإدارة بلون ليلي `#1f1f1f` مع أرقام ذهبية براقة `#FFD700` (`778311135-778898651`).
- **نافذة مراكز البيع والوكلاء (`alert-location`):**
  - عنوان ذهبي مشع: `#FFD700` مع أيقونة الموقع الجغرافي.
  - بيان المراكز: "جميع البقالات في نطاق تغطية الشبكة".
- **نافذة معالجة الأخطاء (`alert-error`):**
  - خلفية معتمة نصف شفافة تغطي الشاشة، مع بطاقة بيضاء تعرض الترجمة الدقيقة للخطأ الصادر من الراوتر ونصيحة للمستخدم.

## 7. نظرة عامة على المشروع وهندسة النظام

هذا المشروع عبارة عن منظومة متكاملة لبوابة التسجيل المحتجزة (**MikroTik Hotspot Captive Portal**) الخاصة بـ **شبكة الكاري نت اللاسلكية**. صُممت المنظومة لتخدم غرضين رئيسيين:

1. **العمل المباشر كنظام Hotspot كامل على أجهزة راوتر بورد مايكروتك (MikroTik RouterOS)** بجميع إصداراته (v6.x و v7.x).
2. **العمل كمحاكي ويب سحابي تفاعلي (Local Simulator & Dev Server)** مبني باستخدام بيئة **Node.js و Express**، مما يتيح معاينة القوالب، وتجربة تسجيل الدخول، وفحص عدادات الاستهلاك والوقت، وتصدير حزمة جاهزة للمايكروتك بنقرة زر واحدة دون الحاجة لوجود راوتر فعلي أثناء الاختبار والتطوير.

### الخصائص المعمارية الأساسية:
- **دعم تسجيل الدخول بنظام الكرت الموحد (Voucher Code):** حيث يكون اسم المستخدم هو نفسه كلمة المرور عبر ميزة النسخ التلقائي `copyTextValue()`.
- **التشفير الآمن عبر بروتوكول HTTP-CHAP:** استخدام مكتبة `md5.js` لتشفير كلمة المرور مع `chap-challenge` و `chap-id` قبل إرسالها إلى الراوتر، مع دعم التراجع التلقائي لـ HTTP-PAP إذا كان السيرفر معداً لذلك.
- **جدار حماية أمامي ضد الهجمات والتخمين (Brute-Force Blocker):** حظر مؤقت للمستخدم عند تجاوز عدد المحاولات الخاطئة (3 إلى 5 محاولات) لمدة محددة مع عداد تنازلي حي في صفحة `block.html`.
- **حفظ بيانات الدخول وتسهيل إعادة الاتصال:** عبر كوكيز المتصفح (`hotCookie.min.js`) مع منع التكرار اللانهائي في حال حدوث خطأ.
- **تنقية وتصحيح مدخلات المستخدم:** عبر `hotInImprover.min.js` لتحويل الأرقام العربية (٠١٢٣) إلى إنجليزية (0123) وإزالة المسافات التي تسبب فشل الدخول أثناء نسخ ولصق الكود.
- **لوحة بيانات حية للاستهلاك (`status.html`):** حساب فوري للوقت المستهلك، والوقت المتبقي، وحجم البيانات المستهلكة، والرصيد المتبقي بوحدات عربية ذكية (كيلوبايت، ميجابايت، جيجابايت).
- **تعريب شامل واحترافي لجميع رسائل وأخطاء المايكروتك:** عبر ملف `errors.txt` ومطابقات JavaScript داخل صفحة الدخول.
- **التوافق القياسي مع بروتوكول WISPr 1.0:** للتوافق مع مساعدات تسجيل الدخول في الهواتف الذكية (Android Captive Portal, Apple Captive Network Assistant CNA, Windows NCSI).

## 9. الفحص الشامل والدقيق لكل ملف ومجلد في المنظومة

| الملف | الوظيفة الدقيقة والخصائص التقنية |
| :--- | :--- |
| **`login.html`** | صفحة تسجيل الدخول الرئيسية المتطورة بتصميم زجاجي ياقوتي فاخر (Glassmorphism). تتضمن شريط تنقل سفلي عائم، ومؤشر حالة السيرفر المباشر مع وميض نبضي، وشعار البث المتحرك بموجات متتالية، وحقل كرت ذكي، وتشفير CHAP/PAP، وقائمة السرعات، ونظام الحظر وحفظ الكوكيز وتصحيح الأرقام التلقائي. |
| **`status.html`** | صفحة لوحة التحكم التي يراها المشترك بعد فتح الإنترنت. تعرض ساعة عربية متزامنة، والوقت المستهلك `$(uptime)`، والوقت المتبقي للجلسة `$(session-time-left)`، وحجم التنزيل والرفع المحول لعربيات القياس `readablizeBytes($(bytes-total))`، والرصيد المتبقي `$(remain-bytes-total)`، وزر تسجيل الخروج مع مسح الكوكيز. |
| **`logout.html`** | صفحة إشعار انتهاء الجلسة. تظهر جدولاً يحتوي على إحصائيات الجلسة المغلقة: اسم المشترك، عنوان IP وعنوان MAC، والمدة المستهلكة، وحجم البايتات المتبادلة عبر `$(bytes-in-nice)` و `$(bytes-out-nice)`، مع زر العودة لصفحة الدخول. |
| **`block.html`** | تظهر للعميل إذا تجاوز عدد المحاولات الخاطئة المحددة في `hotBlocker.min.js`. تعرض رسالة: *"لقد تم حظرك بسبب محاولات تسجيل الدخول الكثيرة الخاطئة"*، مع عداد تنازلي حي يحسب الدقائق والثواني المتبقية ويفك الحظر تلقائياً. |
| **`alogin.html`** | صفحة وسيطة تنقل المستخدم فور إتمام المصادقة بنجاح إلى صفحة `status.html` وتفتح نافذة منبثقة مصغرة لمتابعة الرصيد في حال كان خيار `$(popup)` مفعل في الراوتر. |
| **`rlogin.html`** | صفحة إعادة التوجيه لبروتوكول WISPr، تحتوي على رأس XML مخفي يتعرف عليه نظام أندرويد وiOS لتسجيل الدخول التلقائي وفتح المتصفح النظامي. |
| **`redirect.html`** | تعيد توجيه المشترك إلى الموقع الأصلي الذي كان يطلبه قبل اعتراضه من قبل البوابة عبر المتغير `$(link-redirect)`. |
| **`radvert.html`** | تدير الإعلانات الترويجية للشبكة في نافذة منبثقة بمجرد الاتصال إذا كانت مفعلة في خيارات سيرفر المايكروتك `advert-pending`. |
| **`error.html`** | صفحة بديلة خفيفة الوزن تظهر للمستخدم إذا فشل الاتصال مع توضيح سبب الخطأ عبر المتغير `$(error)`. |
| **`prices.html`** | صفحة استعراض أسعار الباقات بتصميم عصري (Cards) متوافقة مع شاشات الهواتف مع زري عودة للبوابة الرئيسية وصفحة الاستهلاك. |
| **`errors.txt`** | ملف نصي خاص بالمايكروتك يقوم بترجمة رسائل الخطأ الداخلية الصادرة عن RouterOS إلى اللغة العربية الفصحى المبسطة قبل إرسالها إلى المتصفح. |
| **`api.json`** | ملف يعيد كائن JSON متوافق مع مواصفة IETF RFC 8952 لتطبيقات الهواتف الذكية لمعرفة هل المستخدم محتجز (Captive)، ورابط تسجيل الدخول، والرصيد المتبقي بالثواني والبايتات. |
| **`md5.js`** | تطبيق جافا سكريبت لخوارزمية RFC 1321 لتوليد التجزئة الأمنية للمصادقة المشفرة بنمط CHAP. |

## 10. آلية الربط مع سيرفر المايكروتك ومتغيرات النظام (MikroTik Variables)

يقوم محرك الـ Hotspot في نظام MikroTik RouterOS باستبدال العلامات البرمجية التي تبدأ بـ `$(...)` بالقيم الحقيقية للعميل أثناء تمرير الصفحات:

| المتغير البرمجي | الصفحة المستخدم فيها | الوصف الفني وقيمته في المايكروتك |
| :--- | :--- | :--- |
| `$(link-login-only)` | `login.html` | رابط المعالج الداخلي في المايكروتك المسؤول عن استقبال بيانات النموذج (مثلاً: `http://192.168.88.1/login`). |
| `$(link-login)` | `logout.html`, `error.html` | الرابط المؤدي لصفحة تسجيل الدخول الأساسية. |
| `$(link-logout)` | `status.html`, `logout.html` | الرابط المسؤول عن قطع جلسة العميل في السيرفر وتفريغ جداول الـ Active. |
| `$(link-status)` | `login.html`, `alogin.html` | رابط صفحة الحالة لمتابعة الاستهلاك والرصيد. |
| `$(link-orig)` | `login.html`, `radvert.html` | الموقع الأصلي الذي طلبه المشترك قبل اعتراض اتصاله (مثل `http://google.com`). |
| `$(link-redirect)` | `redirect.html`, `alogin.html` | رابط التوجيه النهائي للعميل بعد تمام المصادقة. |
| `$(username)` | `login.html`, `status.html`, `logout.html` | اسم المستخدم المسجل أو المراد دخوله. |
| `$(password)` | `login.html` | كلمة المرور المشفرة أو الصريحة. |
| `$(ip)` | `logout.html`, `errors.txt` | عنوان IP المخصص لجهاز العميل من حزمة الـ DHCP Pool. |
| `$(mac)` | `logout.html`, `status.html` | العنوان الفيزيائي لكرت شبكة العميل (MAC Address). |
| `$(uptime)` | `status.html`, `logout.html` | المدة الزمنية النشطة التي قضاها العميل في هذه الجلسة (ساعات/دقائق/ثواني). |
| `$(session-time-left)` | `status.html`, `logout.html`, `api.json` | الوقت المتبقي لحساب العميل قبل قطع الاتصال. |
| `$(bytes-total)` | `status.html` | إجمالي البايتات المستهلكة في الجلسة الحالية (رفع + تنزيل). |
| `$(remain-bytes-total)`| `status.html`, `api.json` | رصيد التحميل المتبقي للكرت بالبايت في حال كانت الباقة محددة بحجم كوته. |
| `$(bytes-in-nice)` | `logout.html` | حجم البيانات المستلمة بصيغة سهلة القراءة (مثل `14.2 MB`). |
| `$(bytes-out-nice)` | `logout.html` | حجم البيانات المرسلة بصيغة سهلة القراءة. |
| `$(chap-id)` | `login.html` | المعرف العشوائي المشترك المولد من السيرفر لكل محاولة لتأمين التشفير. |
| `$(chap-challenge)` | `login.html` | التحدي العشوائي المشفر المطلوب دمجه مع كلمة المرور لمنع هجمات التكرار (Replay Attacks). |
| `$(error)` | `login.html`, `error.html`, `block.html` | نص رسالة الخطأ القادمة من المايكروتك عند فشل محاولة الدخول. |
| `$(refresh-timeout-secs)` | `status.html` | مهلة التحديث التلقائي لصفحة الحالة بالثواني المحددة في بروفايل الهوتبوت. |

## 11. دورة حياة تسجيل الدخول والمصادقة (CHAP vs PAP)


## 12. إعدادات السرعات واختيار الباقات وتوزيع الباندويث (Speed Control)

### أ. كيفية عمل اختيار السرعة في واجهة البوابة (`login.html`):
تحتوي صفحة الدخول على عنصر اختيار سرعة للمستخدم قبل الضغط على دخول:
```html
<select name="domain">
    <option value="512K/512K">سرعة ضعيفة</option>
    <option value="100M/100M" selected>سرعة قوية</option>
</select>
```
ويتم تمرير القيمة المختارة للمايكروتك عبر المتغير `speed` في النموذج المشفر `sendin`.

### ب. تطبيق السرعة في المايكروتك:
في المايكروتك ضمن `/ip hotspot user profile` في خانة **on-login**:
```routeros
:local uname "$user";
:local speed [/ip hotspot active get [find user=$uname] domain];
:if ($speed = "512K/512K") do={
    /queue simple set [find name=("<hotspot-" . $uname . ">")] max-limit=512k/512k
} else={
    /queue simple set [find name=("<hotspot-" . $uname . ">")] max-limit=10M/50M
}
```

```routeros
add list=UPDATE_DOMAINS address=ntservicepack.microsoft.com

add list=UPDATE_DOMAINS address=appldnld.apple.com

```

## 17. الرسائل والأخطاء القادمة من المايكروتك وقاموس التعريب (Error Handling)

| رسالة المايكروتك الأصلية (`$(error)`) | المعنى الفني للخطأ | الرسالة العربية المعروضة للمشترك في البوابة |
| :--- | :--- | :--- |
| `simultaneous session limit reached` | الكرت مسجل دخول حالياً في جهاز آخر | **"لا يمكن تسجيل الدخول أكثر من مرة"** |
| `invalid username or password` | خطأ في كتابة رقم الكرت أو كلمة المرور | **"خطأ في إسم المستخدم او كلمة المرور"** |
| `invalid password` | كلمة المرور غير صحيحة | **"تأكد من كتابة كلمة المرور بشكل صحيح"** |
| `access denied at this time` | الحساب مقيد بوقت محدد في اليوم | **"بطاقة لا يمكن استخدامها في هذا الوقت"** |
| `uptime limit reached` | انتهت ساعات العمل المتاحة للكرت | **"عذرا لقد انتهى الوقت المتاح لك.."** |
| `no more sessions are allowed for user` | تجاوز حد الجلسات المتزامنة | **"لا يمكن تسجيل الدخول اكثر من مرة"** |
| `no valid profile found` | انتهاء الصلاحية الزمنية للكرت | **"لقد انتهت صلاحية هذه البطاقة"** |
| `transfer limit reached` / `traffic limit` | استنفاد رصيد التحميل أو الجيجابايت | **"لا يمكنك تسجيل الدخول , انتهى رصيد هذه البطاقة"** |
| `invalid Calling-Station-Id` / `not allowed from this MAC` | الكرت مقترن بجهاز آخر (MAC Lock) | **"هذا الحساب مقترن بجهاز آخر"** |
| `not found` | رقم الكرت غير مسجل في السيرفر | **"اسم المستخدم غير موجود تأكد من كتابته بشكل صحيح"** |
| `radius timeout` | عدم استجابة سيرفر الـ Radius | **"عزيزي المشترك نعتذر عن انقطاع الخدمة بسبب الصيانة"** |

## 19. تسجيل الخروج وقطع الاتصال ومسح الجلسة (Logout & Disconnect)

تمت هندسة عمليتي الخروج وقطع الاتصال وفقاً لأعلى معايير مايكروتك الرسمية مع معالجة حصرية للسرعة الفائقة وانعدام الوميض (Zero-Latency & Flicker-Free Architecture):

1. **التمييز الدقيق بين زري الخروج في صفحة الحالة ():**
   - **زر تسجيل الخروج الآمن (الأزرق الملكي):**
     - يُرسل طلب الخروج إلى  مع معامل  (لحفظ بيانات الكرت والرصيد للعودة لاحقاً).
     - يتم التحويل المباشر الفوري برمجياً إلى صفحة تسجيل الدخول  مباشرة في طلب واحد عبر بروتوكول HTTP 302 دون تحميل شاشات وسيطة نهائياً، مما يقضي تماماً على الشاشة السوداء أو أي وميض أو تأخير.
     - تظهر رسالة إشعار علوية فخمة وسلسة: **"تم تسجيل الخروج بنجاح وحفظ بياناتك ووقتك المتبقي بأمان"**.
   - **زر قطع الاتصال الفوري (القرمزي الفاخر):**
     - يُرسل طلب الخروج إلى  مع معامل  لمسح كوكيز الجلسة نهائياً من الراوتر والمتصفح.
     - تُعرض شاشة تقرير الجلسة المنتهية الفاخرة () بكافة التفاصيل الدقيقة: اسم المشترك، IP، MAC، مدة الاتصال، والبيانات المستلمة والمرسلة بدقة.
     - زر **"تسجيل الدخول مجدداً"** ينقل المشترك فوراً إلى  عبر دالة  دون ترك صفحات عالقة في سجل المتصفح وبسلاسة تامة.

## 24. التحديثات والتحسينات الهندسية الفائقة: السرعة وانعدام الوميض (Zero-Flicker Architecture)

تم إجراء تدقيق برمجي عالي المستوى لمنع أي تشوه بصري (Visual Glitch) أو شاشة سوداء أو وميض أثناء التنقل بين بوابات الهوتبوت:

### 1. كيف تم حل مشكلة الشاشة السوداء والوميض نهائياً عند تسجيل الخروج؟
* **المشكلة السابقة:** عند الضغط على تسجيل الخروج، كان يتم إرسال طلب إلى الراوتر الذي يُرجع صفحة logout.html كصفحة وسيطة، وكانت الخلفية تظهر بألوان داكنة وتنتظر تنفيذ سكربت التوجيه إلى login.html، مما كان يُحدث لحظة وميض (Flicker) وانتقالاً غير مريح للعين.
* **الحل الهندسي المطبق:** 
  1. تم تحويل التوجيه ليتم مباشرة عبر السيرفر (Direct HTTP 302 Redirection) فورياً من مسار الخروج إلى login.html?logout=success دون فتح أو تحميل صفحة وسيطة إطلاقاً لعملية تسجيل الخروج.
  2. تم إخفاء body صفحة logout.html افتراضياً، بحيث لا يتم إظهاره إلا إذا كان الطلب هو "قطع اتصال" فعلي (disconnect)، مما يمنع نهائياً وميض الصفحة قبل التوجيه.

### 2. التوجيه الفوري لصفحة الحالة عند تسجيل الدخول (Zero-Latency Login):
* تم تعديل صفحة alogin.html بحقن دالة window.location.replace("$(link-status)") في أول سطر من الترويسة <head> قبل تحميل الـ DOM أو معالجة الخطوط، مع ترويسة <meta http-equiv="refresh" content="0; url=$(link-status)">.
* تم توحيد لون الخلفية المتدرج الملكي #2b000e في كافة الصفحات (login.html, alogin.html, status.html, logout.html) حتى لا تختلف درجة الإضاءة أثناء تبديل الصفحات على شاشات الهواتف.

### 3. سلاسة العودة وتسجيل الدخول مجدداً:
* في شاشة قطع الاتصال (logout.html)، تم ربط زر "تسجيل الدخول مجدداً" بآلية window.location.replace الفورية مع تنظيف مفاتيح الجلسة، مما يمنع تراكم الصفحات في سجل الرجوع (History Stack) ويتيح فتح بوابة الدخول فوراً بضغطة واحدة.
